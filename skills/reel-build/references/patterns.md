# 쇼릴 장면 패턴

검증된 장면 조리법. 좌표는 1920×1080 기준이며, 각 절의 코드만으로 쓸 수 있다. 쇼릴 한 편의 전체 구조는 `example-showreel-reel.js`(이 플러그인의 작동 방식을 소개하는 30초 쇼릴)에서 볼 수 있다.

## 목차
1. 타이틀: 두 줄 올라오기 + 커서 블록
2. 큰 숫자 카운트업 → 축소 → 반박
3. 흩어진 격자가 판정별로 정렬 + 카운터 표
4. 취소선 + 도장 + 흔들림
5. 타임라인(테이프 축 + 눈금 + 연도)
6. 지도 위 경로 이동(키프레임) + 이벤트 + 갈래선
7. 점수 막대 비교 + 추천 칩
8. 타자 질문 → 엔딩 카드
9. 주제 소품(라벨, 바코드, 분포 곡선)

## 1. 타이틀

```js
const w2 = rise('아직 남은 것', 160, 690, .55, t, { k:'d', s:170, c:C.blue, st:.05 });
if (t > 1.05) { ctx.fillStyle = C.orange; ctx.fillRect(160 + w2 + 26, 690 - 128, 34, 140); }  // 반환 폭으로 커서 위치
typeOn('부제 · 모노 · 짧게', 164, 800, 1.15, t, 48, { k:'m', s:26, w:500, c:C.ink, al:.75 });
```
- 두 줄의 시작을 0.3초 엇갈리게 한다. 둘째 줄을 강조색으로.
- 위아래 테이프를 `eoX`로 가로질러 그으면 무대가 열리는 느낌이 난다.

## 2. 큰 숫자

```js
const v = 22.82 * eoX(P(t, .1, 1.0));                  // 카운트업: text()로, 소수점 자리 고정
const e = eio(P(t, 1.25, 1.65));                        // 축소 이동
const size = lerp(300, 150, e), y = lerp(640, 450, e);
text(v.toFixed(2) + '%', 150, y, { k:'m', s:size, w:700, c:C.paper, ls:-size * .03 });
// 반박: 빨간 취소선(폭은 최종 크기로 measure), 그 아래 새 사실이 rise로 크게
```
- 큐: `ticks: [[카운트 시작, 끝]]`, 반박 숫자에 `booms`, 취소선에 `swishes`.
- 숫자가 줄어든 뒤 생긴 오른쪽 빈자리에 근거 도식(분포 곡선 등)을 그린다.

## 3. 판정 격자

- 항목 N개를 셀로 만든다. 등장 순서는 무작위 순열(`PERM`), 목적지는 판정별 정렬 위치.
- 등장: `eback(P(t, .35 + PERM[k] * .007, ...))`로 셀 크기가 튀어나옴 → 큐 `pops`.
- 정렬: `eio(P(t, 1.5 + k * .008, ...))`로 이동, `sin(mp * π) * 18`만큼 위로 호를 그림 → 큐 `whooshes`(정렬 끝).
- 오른쪽 표: 판정별 스와치 + 두 자리 카운터(`padStart(2, '0')`) + 라벨 + 설명. 카운터 구간에 `ticks`.
- 정렬이 끝나면 강조할 줄에 밑줄을 긋고(`swishes`) 한 문장 결론을 아래에 둔다.

## 4. 취소선 + 도장

```js
const sh = t > 1.35 ? (1 - P(t, 1.35, 1.8)) * 12 : 0;              // 도장 순간 흔들림
ctx.translate(Math.sin(t * 95) * sh, Math.cos(t * 80) * sh * .6);
// 주장 문장 rise → 1.0초에 주황 취소선(eoX) → 1.3초에 stamp('폐기', …, P(t, 1.3, 1.55))
// 도장 뒤 주장 글자는 globalAlpha를 1 → .38로 낮춘다
```
- 큐: `swishes`(취소선), `drops` + `hits`(도장 착지 = 1.3 + .4 × .25).
- 도장은 문장 끝과 약간 겹치게 놓는다(`stamp`는 자동으로 overlapOk).

## 5. 타임라인

- 노란 테이프 축(`fillRect`, 폭 = 1600 × `eoX`), 사건마다 눈금(`eback`으로 길이가 튀어나옴), 연도(모노 56), 설명 두 줄(34 / 24).
- 사건은 같은 간격(x = 160 + i × 400)으로 둔다. 실제 연도 간격을 반영하지 않으므로 축 눈금이나 비율을 암시하는 장식은 넣지 않는다.
- 마지막 사건(현재)을 강조색으로. 큐: `plucks` 올라가는 음(74, 77, 81, 86).

## 6. 지도 위 경로

```js
const PATH = [[x, y, flag, ...], ...];   // flag 1 = 멈춰서 처리, 2 = 예외 정지
// 불러올 때 한 번: 거리/속도로 키프레임 시각 계산, 처리 지점마다 DWELL 추가, 마지막 구간은 감속(eo3)
function cartAt(t){ /* 키프레임 보간, 진행 방향 각도 */ }
```
- 처리된 칸은 불투명 강조색으로 채웠다가 안쪽 사각형으로 줄여 표시(반투명 금지).
- 예외 지점: 칸이 빨갛게 깜빡임 → 빨간 동심원 → 위로 지시선 → 코드 라벨(`C-05-02 · 재고 없음`).
- 정지 0.5초 뒤 나머지 지도를 바탕색 55%로 덮고(초점), 예외 지점에서 오른쪽 선택지로 `bezierPart` 갈래선을 차례로 그린다. 현행 방식은 점선·회색.
- 큐: 처리 지점 `scans`, 예외 `alarms`, 정지~재출발 `freezes`, 다음 장면까지 `builds` + `risers`, 갈래선 `plucks`.

## 7. 점수 막대

- 일정 척도(px/점)를 하나로 고정하고 0·10·20·30 눈금선을 그린다. 막대 끝에 값(모노 60)이 카운트업.
- 행 왼쪽: 문자 표식(A/B/C) + 제목 + 한 줄 설명. 추천 행은 강조색 막대 + 노란 테두리 `rectDraw` + 칩.
- 큐: 막대 시작마다 `plucks`, 칩 등장 `blips`.

## 8. 타자 질문 → 엔딩

- 질문을 `typeOn`(cps 15, 커서) → 아래 조건 문장 `rise` → 1.85초에 묶음 전체를 위로 70px 이동하며 사라짐.
- 엔딩: 모노 자간 넓은 라벨(`PROJECT SCOPE  A`) → 디스플레이 150 제목 → 본문 한 줄 → 흐르는 줄무늬 띠 → 요약 숫자 한 줄(모노, 옅게).
- 큐: 글자마다 `keys`, 조건 문장 ~ 엔딩 사이 `risers`, 엔딩 제목에 `end`.

## 9. 주제 소품

- **위치 라벨 + 바코드**: 흰 라벨, 윗단 강조 띠, 모노 코드, 난수 폭 바코드, 스캔 레이저(빨간 선 + `shadowBlur` 깜빡임), 도장.
- **분포 곡선**: 정규분포 선을 클립 폭으로 그려 나가고, 양쪽 꼬리를 반투명으로 칠하고, 임계선(점선)과 관측선을 라벨과 함께 표시.
- 원칙: 주제의 실제 표기법(단위, 코드 형식, 문서 양식)을 소품으로 쓴다. 이런 디테일 하나가 "템플릿으로 찍어낸 영상" 느낌을 없앤다.
